Acceleration Guard
==================
1. Open index.html in Chrome or Edge to use it locally (screen sharing works best this way).
2. To put it online, upload this folder to Netlify, GitHub Pages or Cloudflare Pages.
3. To show ads, edit index.html and fill in ADS_CLIENT and ADS_SLOT with your Google AdSense ids.
4.  Keep pro-codes-PRIVATE.txt separate and send one code per paying customer.
